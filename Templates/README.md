# Templates

Ce dossier contient tous les templates et modèles réutilisables pour Tech Tribe.

## Contenu

- **Code** : Templates de code (boilerplates, starters)
- **Documents** : Templates de documents (rapports, spécifications)
- **Workflows** : Templates de workflows réutilisables
- **Email** : Templates d'emails et communications
- **Notion** : Templates de pages et bases de données Notion

## Structure

```
Templates/
├── code/             # Templates de code
├── documents/        # Templates de documents
├── workflows/        # Templates de workflows
├── email/            # Templates d'emails
└── notion/           # Templates Notion
```

## Utilisation

1. Copier le template dans votre projet
2. Adapter les variables et configurations
3. Personnaliser selon vos besoins
4. Ne pas modifier les templates sources directement

## Conventions

- Utiliser des placeholders clairs : `{{VARIABLE_NAME}}`
- Documenter les variables requises
- Inclure des exemples d'utilisation
- Versionner les templates majeurs
- Ajouter un changelog pour les modifications

## Contribution

Pour ajouter un nouveau template :
1. Créer le fichier dans le dossier approprié
2. Ajouter la documentation d'utilisation
3. Tester le template avant de commiter
4. Mettre à jour ce README avec la référence
