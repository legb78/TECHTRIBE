# Archive

Ce dossier contient les éléments obsolètes, anciens projets et documents historiques.

## Objectif

Conserver la mémoire des projets passés tout en maintenant l'organisation principale propre et à jour.

## Contenu

- **Projets obsolètes** : Anciens projets non maintenus
- **Documentation périmée** : Anciennes versions de documents
- **Code legacy** : Ancien code pour référence historique
- **Workflows désactivés** : Workflows non utilisés

## Structure

```
Archive/
├── YYYY-MM/          # Dossiers par date d'archivage
│   ├── workflows/
│   ├── scripts/
│   ├── documentation/
│   └── designs/
└── legacy-projects/  # Anciens projets complets
```

## Conventions d'archivage

1. **Date** : Préfixer avec la date d'archivage (YYYY-MM)
2. **Raison** : Documenter pourquoi l'élément est archivé
3. **Origine** : Indiquer de quel dossier provient l'élément
4. **Référence** : Conserver les liens vers documentation associée

## Processus d'archivage

1. Créer un dossier daté si nécessaire
2. Déplacer les fichiers obsolètes
3. Ajouter un fichier `ARCHIVE_INFO.md` avec :
   - Date d'archivage
   - Raison de l'archivage
   - Origine des fichiers
   - Responsable de l'archivage
4. Mettre à jour ce README avec une entrée
