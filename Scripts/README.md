# Scripts

Ce dossier regroupe tous les scripts d'automatisation et utilitaires développés pour Tech Tribe.

## Contenu

Scripts organisés par langage et fonction :
- **Python** : Scripts d'automatisation, traitement de données
- **JavaScript/Node.js** : Scripts backend et automatisations
- **Bash/Shell** : Scripts système et DevOps
- **Autres** : Scripts spécifiques (PowerShell, etc.)

## Structure

```
Scripts/
├── python/           # Scripts Python
├── javascript/       # Scripts JS/Node
├── shell/            # Scripts Bash/Shell
└── utils/            # Utilitaires généraux
```

## Conventions de nommage

- Utiliser des noms descriptifs en minuscules avec tirets : `mon-script.py`
- Inclure un en-tête avec description et usage dans chaque script
- Documenter les dépendances requises (requirements.txt, package.json, etc.)
- Versionner les scripts critiques

## Bonnes pratiques

1. Tester les scripts avant de les commiter
2. Gérer les erreurs et exceptions
3. Inclure des logs pour le debugging
4. Documenter les paramètres et options dans le code
5. Ajouter un fichier README pour les scripts complexes
