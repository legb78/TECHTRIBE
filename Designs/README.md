# Designs

Ce dossier regroupe tous les assets de design et éléments visuels de Tech Tribe.

## Contenu

- **UI/UX** : Maquettes d'interfaces et wireframes
- **Branding** : Logos, charte graphique, identité visuelle
- **Assets** : Images, icônes, illustrations
- **Prototypes** : Prototypes interactifs et fichiers sources

## Structure

```
Designs/
├── ui-ux/            # Maquettes UI/UX
├── branding/         # Identité visuelle
├── assets/           # Images et ressources
├── prototypes/       # Prototypes interactifs
└── exports/          # Exports finaux
```

## Formats supportés

- **Figma** : Fichiers et liens Figma
- **Adobe** : PSD, AI, XD
- **Sketch** : Fichiers Sketch
- **Images** : PNG, JPG, SVG
- **Vidéos** : MP4, GIF

## Conventions

- Nommer les fichiers de façon descriptive
- Organiser par projet ou composant
- Inclure les versions sources éditables
- Exporter les assets dans /exports
- Documenter les décisions de design importantes

## Guidelines

- Respecter la charte graphique établie
- Utiliser les composants réutilisables
- Optimiser les assets pour le web (compression, formats adaptés)
- Versionner les designs majeurs
- Inclure les guides de style et design systems

## Collaboration

- Partager les liens Figma/prototypes dans la documentation
- Commenter les décisions de design
- Mettre à jour ce README avec les nouveaux projets
